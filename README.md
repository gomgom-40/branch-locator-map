# Branch Locator Map | محدد الفروع على الخريطة

A simple and practical **Branch Locator** web application built using **Google Maps JavaScript API**.

تطبيق ويب بسيط وعملي لعرض الفروع ومراكز الخدمة على خريطة جوجل، مع إمكانية البحث عن العناوين وعرض بيانات كل فرع بشكل واضح.

---

## 🧠 فكرة المشروع | Project Idea

The goal of this project is to provide an easy way for users to:

* View all company branches on an interactive map
* Distinguish between different branch types using custom markers
* Click on any branch to see its details (address & phone)
* Search for a location and display it on the map

هدف المشروع هو تسهيل:

* عرض جميع الفروع على خريطة تفاعلية
* التمييز بين أنواع الفروع باستخدام أيقونات مختلفة
* عرض بيانات كل فرع عند الضغط عليه
* البحث عن عنوان معين وإظهاره على الخريطة

---

## ⚙️ المميزات | Features

* Google Maps integration

* Custom markers based on branch type

* Single reusable InfoWindow

* Data-driven design (no hard-coded indices)

* Address geocoding and user pin

* دمج كامل مع Google Maps

* أيقونات مختلفة حسب نوع الفرع

* نافذة معلومات واحدة قابلة لإعادة الاستخدام

* تنظيم البيانات بشكل نظيف وقابل للتوسعة

* البحث عن العناوين وإظهار موقع المستخدم

---

## 📌 الاستخدام | Usage

1. Add your Google Maps API key in `index.html`
2. Open the project in a browser
3. Click on any marker to view branch details
4. Use the search box to geocode an address
